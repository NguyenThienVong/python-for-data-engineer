# Python for Data Engineering

**Based on:** Python for Data Engineering – Full Course (Pandas, Polars, SQL, APIs, Pytest, Airflow).

A hands-on learning repository documenting my journey toward becoming a Data Engineer.

## Tech Stack

- Python
- Pandas & Polars
- SQL
- APIs
- Pytest
- Apache Airflow

## Learning Goals

- Practice Python for Data Engineering.
- Process and transform data.
- Work with databases and APIs.
- Build ETL pipelines.
- Practice testing and workflow orchestration.

## Getting Started

```bash
git clone https://github.com/NguyenThienVong/python-for-data-engineer.git

cd python-for-data-engineer

python -m venv .venv

pip install -r requirements.txt
```
